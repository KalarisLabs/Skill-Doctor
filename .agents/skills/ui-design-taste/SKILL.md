# UI Design Taste & Aesthetic Excellence

Use this skill when designing or authoring frontend user interfaces, layouts, dashboards, and visual components.

## Core Design Principles
1. **Visual Excellence over Bare MVPs:** Interfaces should create a stunning, premium first impression with bespoke dark-mode themes, polished glassmorphism, tailored gradients, and deliberate typography.
2. **Harmonious Color Palette:** Avoid raw primary colors. Use carefully calibrated HSL/OKLCH color scales with distinct semantic roles (primary, muted, accent, borders, severity tags).
3. **Hierarchy & Depth:** Use subtle borders (`border-border/40`), elevated surface cards (`bg-card/50 backdrop-blur-sm`), and soft glows (`shadow-lg ring-1 ring-white/5`) to establish depth.
4. **Micro-Interactions & Liveliness:**
   - Smooth transitions on hover (`transition-all duration-200 hover:border-primary/50`).
   - Subtle pulse animations for live status indicators.
   - Dynamic SVG meters and progress bars for metric visualization.
5. **Information Density with Clean Whitespace:** Structure complex data (such as security findings and logs) into clear sections, badges, and expandable cards with clean monospace font for hashes, paths, and IDs.
