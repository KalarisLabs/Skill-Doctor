# Adopters

## Submission Policy

**Entries are added only by the adopting organization itself via pull request.** Project maintainers do not add adopters on anyone's behalf. To add your organization, open a PR with a brief description of how you use Skill Doctor (e.g., CI gate, skill marketplace screening, security review workflow).
