# Support Guidelines

We are glad you are using Skill Doctor! To get the quickest assistance, please direct your questions and reports to the appropriate channels.

---

## 1. Where to Ask Questions

For usage questions, general troubleshooting, architectural inquiries, or showing off how you integrated Skill Doctor:

👉 **[GitHub Discussions](https://github.com/KalarisLabs/Skill-Doctor/discussions)**
- **Q&A**: Questions on CLI syntax, exit codes, SARIF outputs, or configuration.
- **Rule Proposals**: Brainstorming new detection rules for SDTM-v1 threat classes.
- **Show and Tell**: Sharing workflows, CI configurations, and custom tooling.

---

## 2. Where to Report Bugs & Detector Issues

For defects, unexpected scanner crashes, false positives, or false negatives:

👉 **[GitHub Issues](https://github.com/KalarisLabs/Skill-Doctor/issues)**
- **Bug Report**: Unexpected scanner errors, runtime crashes, or CLI failures.
- **False Positive**: Legitimate skills or scripts incorrectly flagged by a detector.
- **False Negative**: Evasion samples or attacks that should have been detected.
- **Feature Request**: Proposals for new subcommands, output formats, or platform support.

---

## 3. Where to Report Security Vulnerabilities

**DO NOT open public GitHub issues for security vulnerabilities or zero-day exploits in Skill Doctor.**

👉 **Private Security Disclosure**:
- Submit via [GitHub Security Advisories](https://github.com/KalarisLabs/Skill-Doctor/security/advisories/new)
- Or email: **`security@kalarislabs.com`**

Please see our full [SECURITY.md](SECURITY.md) policy for response timelines and disclosure guidelines.
